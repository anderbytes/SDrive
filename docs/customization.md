# Customize

Customize contains Appearance, Drive cards and Disconnection categories. New preferences take effect after Save; Cancel discards them. Existing theme and spacing controls retain their preview behavior.

Text size supports 90%, 100% and 115%. Motion supports full, reduced and disabled, with system reduced motion taking precedence. Sidebar mode supports expanded, collapsed and automatic (collapsed at 1100 pixels or below, with the existing mobile navigation at 650 pixels or below). The navigation button changes its state for the session; saving Customize resets that temporary choice.

Card preferences control service, server/folder, mount destination and capacity. Name, state, actions and warnings remain visible; secondary information remains available through drive details. Capacity can show any nonempty combination of bar, percentage and sizes.

Disconnection notices stay in the bottom-right corner. Compact, standard and large sizes are constrained to the monitor work area. Successful results expire independently after a configurable integer delay of 0–60000 milliseconds (default 1000). Zero removes successful results immediately. Active operations and failures never expire automatically.

Preferences persist locally and are included when portable preferences are exported/imported. Older profiles retain existing appearance defaults and the old sidebar choice until a preference is saved. This delivery deliberately does not refresh installers or release packages.
